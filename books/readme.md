## 项目简介

本仓库沿用 to-the-stars 的四层结构：

- `original/`：AO3 原文存档，由 `scripts/update-source.ts` 自动同步；AO3 不可用时回退到 Wayback Machine 固定快照
- `books/`：译文阅读版，站点主内容与 epub 的来源
- `.vitepress/`：站点配置（中文根 locale + `/original/` 英文原文）
- `scripts/build-epub.ts`：从 `books/` 打包 epub

中文翻译进行中：简介与第 1 章已译毕，译名对照表见 `99/`；英文原文可在站点 `/original/` 阅读。
